# SkyCast Weather App

A Next.js weather website styled with Tailwind CSS. Live conditions come from the free [Open-Meteo](https://open-meteo.com/) API.

## Pages

- **Home** — header, weather display, about section, footer
- **About** — short explanation of the site
- **Services** — weather-related benefits
- **Contact** — simple contact form

The weather display shows temperature, time, interval, humidity, and wind speed. Header and footer are shared components with navigation to every page.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
